# MEASURE: today's generator on both Oak documents, 18 November 2026

The course's MEASURE leg ([castr-course.md](../plans/active/castr-course.md)): what today's
generator does on both Oak API documents at their latest published versions, its Zod output
loaded under the latest Zod 4, scored against the source document by an independent
validator. It reports what is there and decides nothing (owner's decision card, 2 November
2026: "Measure without making decisions, drop the thresholds, we figure out what we have,
then we reflect on it"). The owner and the agent then reflect on it and decide what travels.

A throwaway probe: it ran in a scratch directory outside the repository and changed nothing
in it. Appendix B holds the probe, so every cell can be reproduced.

## Method

1. **Whole document.** The generator ran once on each document as served.
2. **One boundary at a time.** Each of the 32 operations was carved into a document of its
   own (the same `openapi`, `info`, `servers`, `tags`, `externalDocs` and `components`, one
   path, one method) and the generator ran on each, so that a rejection in one operation
   does not hide the others.
3. **Accepted side.** For every slot of every generated operation (each parameter, each
   response with a JSON schema: 188 slots), the probe built values from the source schema
   alone, one per branch choice at every `oneOf`, `anyOf`, `enum` and type list, so that every
   member of every `enum` is reached (the largest has 17). For each
   it then made one changed value per constraint the schema states: a required key
   removed, an unknown key added, a wrong type, a value outside an `enum`, a changed
   `const`, the bound and one past the bound of a `maximum`, and so on. The reference
   validator and the generated Zod schema each decided every value. A row's samples are
   attributed to the constraint the change was aimed at; the reference validator, not the
   probe's intent, says whether each value is valid.
4. **Produced side.** For every value both accepted, the value Zod returned was compared
   with the input.
5. **Boundaries.** The probe read each operation's address, method, identity, parameters
   (with whether each is required),
   statuses, media types, headers and security from the source JSON and compared them
   with the emitted endpoint definition.
6. **Artefacts, compilation, determinism.** Checked by the commands in Appendix A.

The probe is not SPEC-G-5's adequacy proof: it does not delete constraints from generated
output, and array elements are sampled at index 0 only. One value is built per choice
index, applied at every `oneOf`, `anyOf`, `enum` and type list at once, so every member of
each site is reached but not every combination of choices across nested sites.

`probe.mjs`:

```js
// MEASURE probe (throwaway). Scores today's generator, one boundary at a time, against the
// source document read independently of Castr's parser.
//   node probe.mjs <label> <ops-dir> <out-dir>
// The reference validator is Ajv (JSON Schema 2020-12, formats asserting, no coercion, no
// defaults, no removal). Objects whose unknown-key policy the source leaves unstated are closed
// by closeUnstated() below (SPEC-P-1), a transformation that shares nothing with Castr.
import { readFileSync, writeFileSync, existsSync } from 'node:fs';
import path from 'node:path';
import { pathToFileURL } from 'node:url';
import { isDeepStrictEqual } from 'node:util';
import Ajv2020 from 'ajv/dist/2020.js';
import addFormats from 'ajv-formats';

const [label, opsDir, outDir] = process.argv.slice(2);
const index = JSON.parse(readFileSync(path.join(opsDir, 'index.json'), 'utf8'));
const clone = (v) => (v === undefined ? undefined : JSON.parse(JSON.stringify(v)));
const METHODS = ['get', 'put', 'post', 'delete', 'options', 'head', 'patch', 'trace'];

const isObjectSchema = (s) =>
  s.type === 'object' || (Array.isArray(s.type) && s.type.includes('object')) || 'properties' in s;

/** SPEC-P-1 closing: an object that states no unknown-key policy is read as closed. */
function closeUnstated(schema, stats) {
  if (Array.isArray(schema)) return schema.map((s) => closeUnstated(s, stats));
  if (schema === null || typeof schema !== 'object') return schema;
  const out = {};
  for (const [k, v] of Object.entries(schema)) {
    if (k === 'properties' || k === '$defs' || k === 'patternProperties') {
      out[k] = Object.fromEntries(Object.entries(v).map(([n, s]) => [n, closeUnstated(s, stats)]));
    } else if (['items', 'not', 'additionalProperties', 'propertyNames', 'contains'].includes(k)) {
      out[k] = typeof v === 'object' ? closeUnstated(v, stats) : v;
    } else if (['allOf', 'anyOf', 'oneOf', 'prefixItems'].includes(k)) {
      out[k] = v.map((s) => closeUnstated(s, stats));
    } else if (k === '$ref') {
      out[k] = v.replace(/^#\//, 'doc#/');
    } else out[k] = v; // example, default, const, enum values are data, never schemas
  }
  if (!('$ref' in schema) && isObjectSchema(schema) && !('additionalProperties' in schema)) {
    // Across composition the closing keyword is unevaluatedProperties (SPEC-P-1, Writing).
    const composed = ['oneOf', 'anyOf', 'allOf'].some((k) => k in schema);
    if (composed) out.unevaluatedProperties = false;
    else out.additionalProperties = false;
    out['x-closed-by-profile'] = true;
    if (stats) {
      stats.closed += 1;
      if (composed) stats.closedAcrossComposition = (stats.closedAcrossComposition ?? 0) + 1;
    }
  }
  return out;
}

function makeAjv(doc) {
  const ajv = new Ajv2020({
    strict: false,
    allErrors: false,
    coerceTypes: false,
    useDefaults: false,
    removeAdditional: false,
    validateFormats: true,
  });
  addFormats(ajv);
  const stats = { closed: 0 };
  ajv.addSchema({
    $id: 'doc',
    components: { schemas: closeUnstated(doc.components?.schemas ?? {}, stats) },
  });
  return ajv;
}

const deref = (doc, s) => {
  let cur = s;
  while (cur && cur.$ref)
    cur = cur.$ref
      .replace(/^(doc)?#\//, '')
      .split('/')
      .reduce((o, k) => o[k], doc);
  return cur;
};

/** A value built from the schema alone; `pick` chooses the branch at every composition site. */
function build(doc, s, ajv, pick = 0) {
  s = deref(doc, s);
  if ('const' in s) return clone(s.const);
  if (s.enum) return clone(s.enum[pick % s.enum.length]);
  for (const key of ['oneOf', 'anyOf']) {
    if (s[key]) return build(doc, s[key][pick % s[key].length], ajv, pick);
  }
  const types = Array.isArray(s.type) ? s.type : [s.type];
  const t = types[pick % types.length];
  if (t === 'string') return s.format === 'uri' ? 'https://example.com/a' : 'sample';
  if (t === 'number' || t === 'integer')
    return typeof s.maximum === 'number' ? Math.min(1, s.maximum) : 1;
  if (t === 'boolean') return true;
  if (t === 'null') return null;
  if (t === 'array') {
    const n = Math.max(1, s.minItems ?? 0);
    return Array.from({ length: n }, () => build(doc, s.items ?? {}, ajv, pick));
  }
  if (t === 'object' || s.properties) {
    const o = {};
    for (const [k, p] of Object.entries(s.properties ?? {})) o[k] = build(doc, p, ajv, pick);
    return o;
  }
  return 'sample';
}

const jsonType = (v) => (v === null ? 'null' : Array.isArray(v) ? 'array' : typeof v);
const WRONG = ['__wrong__', 987654.5, true, null, ['__wrong__'], { __wrong__: 1 }];

/** Yields { keyword, at, value } mutations of root, attributed to the constraint at the site. */
function* mutate(doc, schema, root, at, ajv) {
  const s = deref(doc, schema);
  const get = () => at.reduce((o, k) => o[k], root);
  const withAt = (v) => {
    if (at.length === 0) return v;
    const r = clone(root);
    const parent = at.slice(0, -1).reduce((o, k) => o[k], r);
    parent[at.at(-1)] = v;
    return r;
  };
  const without = (key) => {
    const r = clone(root);
    delete at.reduce((o, k) => o[k], r)[key];
    return r;
  };
  const here = get();
  const loc = '/' + at.join('/');
  if (schema.$ref)
    yield {
      keyword: '$ref',
      at: loc,
      value: withAt(here),
      note: 'valid value through a reference',
    };
  if ('const' in s)
    yield {
      keyword: 'const',
      at: loc,
      value: withAt(typeof s.const === 'number' ? s.const + 1 : `${s.const}__x`),
    };
  if (s.enum) yield { keyword: 'enum', at: loc, value: withAt('__not_in_enum__') };
  if (s.type !== undefined) {
    const types = Array.isArray(s.type) ? s.type : [s.type];
    const wrong = WRONG.find(
      (w) =>
        !types.includes(jsonType(w)) && !(jsonType(w) === 'number' && types.includes('integer')),
    );
    yield {
      keyword: Array.isArray(s.type) ? 'type (array of types)' : `type: ${s.type}`,
      at: loc,
      value: withAt(wrong),
    };
    if (Array.isArray(s.type) && s.type.includes('null'))
      yield {
        keyword: 'type (array of types)',
        at: loc,
        value: withAt(null),
        note: 'null admitted',
      };
  }
  if (typeof s.maximum === 'number') {
    yield { keyword: 'maximum', at: loc, value: withAt(s.maximum + 1) };
    yield { keyword: 'maximum', at: loc, value: withAt(s.maximum), note: 'boundary' };
  }
  if (s.format) yield { keyword: `format: ${s.format}`, at: loc, value: withAt('not a uri \\ ^') };
  if (typeof s.minItems === 'number' && Array.isArray(here)) {
    yield { keyword: 'minItems', at: loc, value: withAt(here.slice(0, s.minItems - 1)) };
    yield {
      keyword: 'minItems',
      at: loc,
      value: withAt(here.slice(0, s.minItems)),
      note: 'boundary',
    };
  }
  for (const key of ['oneOf', 'anyOf']) {
    if (!s[key]) continue;
    yield { keyword: key, at: loc, value: withAt({ __matches_no_branch__: 1 }) };
    const branch = s[key].find((b) => ajv.validate(closeUnstated(b), here));
    if (branch) yield* mutate(doc, branch, root, at, ajv);
  }
  if (
    here !== null &&
    typeof here === 'object' &&
    !Array.isArray(here) &&
    (s.properties || isObjectSchema(s))
  ) {
    for (const r of s.required ?? [])
      yield { keyword: 'required', at: `${loc}/${r}`.replace('//', '/'), value: without(r) };
    for (const [k] of Object.entries(s.properties ?? {})) {
      if (!(s.required ?? []).includes(k) && k in here)
        yield {
          keyword: 'optional property (absent)',
          at: `${loc}/${k}`.replace('//', '/'),
          value: without(k),
        };
    }
    const policy =
      !('additionalProperties' in s) && !('unevaluatedProperties' in s)
        ? 'unknown key, policy unstated (closed by profile)'
        : s.additionalProperties === false
          ? 'additionalProperties: false'
          : 'additionalProperties: schema';
    yield { keyword: policy, at: loc, value: withAt({ ...here, __unknown__: 1 }) };
    for (const [k, p] of Object.entries(s.properties ?? {}))
      if (k in here) yield* mutate(doc, p, root, [...at, k], ajv);
  }
  if (Array.isArray(here) && s.items && here.length > 0)
    yield* mutate(doc, s.items, root, [...at, 0], ajv);
}

const tally = new Map(); // keyword -> { agree, disagree, examples: [] }
const bump = (keyword, agree, example) => {
  const t = tally.get(keyword) ?? {
    samples: 0,
    agree: 0,
    disagree: 0,
    refAccepts: 0,
    refRejects: 0,
    examples: [],
  };
  t.samples += 1;
  if (agree) t.agree += 1;
  else {
    t.disagree += 1;
    if (t.examples.length < 3) t.examples.push(example);
  }
  if (example.ref) t.refAccepts += 1;
  else t.refRejects += 1;
  tally.set(keyword, t);
};

const boundary = [];
const facts = {
  ops: 0,
  generated: 0,
  rejected: [],
  slots: 0,
  slotsScored: 0,
  baseInvalid: [],
  produced: { checked: 0, changed: [] },
  defaults: [],
  annotations: { description: [0, 0], example: [0, 0], title: [0, 0] },
  closedByProfile: 0,
};
const check = (op, what, ok, detail) => boundary.push({ op, what, ok, detail });

for (const [name, METHOD, route, operationId] of index) {
  facts.ops += 1;
  const doc = JSON.parse(readFileSync(path.join(opsDir, `${name}.json`), 'utf8'));
  const src = doc.paths[route][METHOD.toLowerCase()];
  const outFile = path.join(outDir, `${name}.ts`);
  if (!existsSync(outFile)) {
    const log = readFileSync(path.join(outDir, `${name}.log`), 'utf8');
    facts.rejected.push({
      op: `${METHOD} ${route}`,
      error: (log.match(/^Error: .*$/m) ?? ['(no Error line)'])[0],
    });
    continue;
  }
  facts.generated += 1;
  const mod = await import(pathToFileURL(outFile).href);
  const ep = mod.endpoints[0];
  const opId = `${METHOD} ${route}`;
  const ajv = makeAjv(doc);

  // Boundary facts, source read here and not through Castr.
  check(opId, 'one endpoint emitted', mod.endpoints.length === 1, `${mod.endpoints.length}`);
  check(opId, 'address (path template)', ep.path === route, `${ep.path}`);
  check(opId, 'method', ep.method === METHOD.toLowerCase(), `${ep.method}`);
  check(
    opId,
    'identity (operationId)',
    ep.alias === operationId || ep.operationId === operationId,
    `${ep.alias}`,
  );
  const srcParams = src.parameters ?? [];
  const outParams = (ep.parameters ?? []).filter((p) => p.type !== 'Body');
  check(
    opId,
    'parameter names and locations',
    isDeepStrictEqual(
      srcParams.map((p) => `${p.in}:${p.name}`).sort(),
      outParams.map((p) => `${p.type.toLowerCase()}:${p.name}`).sort(),
    ),
    outParams.map((p) => `${p.type}:${p.name}`).join(','),
  );
  const srcStatuses = Object.keys(src.responses).sort();
  const outStatuses = Object.keys(ep.responses ?? {}).sort();
  check(
    opId,
    'response status keys',
    isDeepStrictEqual(srcStatuses, outStatuses),
    `source ${srcStatuses} output ${outStatuses}`,
  );
  const srcMedia = Object.entries(src.responses)
    .map(([st, r]) => `${st}:${Object.keys(r.content ?? {}).join('+') || '(none)'}`)
    .sort();
  const outMedia = Object.entries(ep.responses ?? {})
    .map(
      ([st, r]) =>
        `${st}:${r.mediaType ?? r.contentType ?? (r.content ? Object.keys(r.content).join('+') : '?')}`,
    )
    .sort();
  check(
    opId,
    'response media types',
    isDeepStrictEqual(srcMedia, outMedia),
    `source ${srcMedia} output ${outMedia}`,
  );
  if (src.requestBody) {
    const bodyParam = (ep.parameters ?? []).find((p) => p.type === 'Body');
    check(
      opId,
      'request body present',
      bodyParam !== undefined || ep.request?.body !== undefined,
      Object.keys(ep.request ?? {}).join(','),
    );
    check(
      opId,
      'request media type',
      JSON.stringify(ep).includes(Object.keys(src.requestBody.content)[0]) ||
        ep.requestFormat === 'json',
      `requestFormat=${ep.requestFormat}`,
    );
  }
  for (const [st, r] of Object.entries(src.responses)) {
    if (r.headers)
      check(
        opId,
        `response ${st} headers`,
        ep.responses?.[st]?.headers !== undefined,
        JSON.stringify(Object.keys(ep.responses?.[st] ?? {})),
      );
  }
  if (src.security)
    check(
      opId,
      'security requirement on the endpoint',
      'security' in ep,
      Object.keys(ep).join(','),
    );

  // Presence: a parameter the source marks required must refuse an absent value, and an
  // optional one must accept it. Path parameters are always required in OpenAPI.
  for (const p of srcParams) {
    const zod = outParams.find((o) => o.name === p.name)?.schema;
    const required = p.required === true;
    const acceptsAbsent = zod?.safeParse(undefined).success === true;
    check(
      opId,
      `parameter presence (${required ? 'required' : 'optional'})`,
      zod !== undefined && acceptsAbsent === !required,
      `${p.in}:${p.name} acceptsAbsent=${acceptsAbsent}`,
    );
  }

  // Slots: every parameter, the request body, every response with a JSON schema.
  const slots = [];
  for (const p of srcParams)
    slots.push({
      slot: `parameter ${p.in}:${p.name}`,
      schema: p.schema,
      zod: outParams.find((o) => o.name === p.name)?.schema,
      required: p.required === true,
    });
  if (src.requestBody) {
    const media = Object.entries(src.requestBody.content)[0];
    slots.push({
      slot: `request body ${media[0]}`,
      schema: media[1].schema,
      zod: (ep.parameters ?? []).find((p) => p.type === 'Body')?.schema ?? ep.request?.body,
      required: src.requestBody.required === true,
    });
  }
  for (const [st, r] of Object.entries(src.responses)) {
    const media = Object.entries(r.content ?? {})[0];
    if (media?.[1].schema)
      slots.push({
        slot: `response ${st} ${media[0]}`,
        schema: media[1].schema,
        zod: ep.responses?.[st]?.schema,
        required: true,
      });
  }

  for (const { slot, schema, zod, required } of slots) {
    // SLOT_FILTER narrows a run to the slots whose name holds it (used for the isolated body).
    if (process.env.SLOT_FILTER && !slot.includes(process.env.SLOT_FILTER)) continue;
    facts.slots += 1;
    if (zod === undefined || typeof zod.safeParse !== 'function') {
      check(opId, `Zod schema addressable for ${slot}`, false, 'no schema found at the endpoint');
      continue;
    }
    const stats = { closed: 0 };
    const closed = closeUnstated(schema, stats);
    facts.closedByProfile += stats.closed;
    facts.closedAcrossComposition =
      (facts.closedAcrossComposition ?? 0) + (stats.closedAcrossComposition ?? 0);
    let validate;
    try {
      validate = ajv.compile(closed);
    } catch (error) {
      check(opId, `reference validator compiles ${slot}`, false, String(error.message));
      continue;
    }
    facts.slotsScored += 1;
    const decide = (keyword, at, value, note) => {
      const ref = validate(value) === true;
      const result = zod.safeParse(value);
      bump(keyword, ref === result.success, { op: opId, slot, at, note, ref, zod: result.success });
      if (ref && result.success) {
        facts.produced.checked += 1;
        if (!isDeepStrictEqual(result.data, value) && facts.produced.changed.length < 5)
          facts.produced.changed.push({ op: opId, slot, at });
      }
      return ref;
    };
    // The source's own example, where the slot states one.
    const top = deref(doc, schema);
    if ('example' in top) decide('source example (as stated)', '/', top.example, 'example');
    const seen = new Set();
    // 17 is the largest enum in either document; every member of every enum is reached.
    for (let pick = 0; pick < 17; pick += 1) {
      const base = build(doc, schema, ajv, pick);
      const key = JSON.stringify(base);
      if (seen.has(key)) continue;
      seen.add(key);
      if (!decide('constructed value (one per branch choice)', '/', base)) {
        facts.baseInvalid.push({
          op: opId,
          slot,
          pick,
          error: ajv.errorsText(validate.errors).slice(0, 160),
        });
        continue;
      }
      for (const m of mutate(doc, schema, base, [], ajv)) decide(m.keyword, m.at, m.value, m.note);
    }
    // SPEC-P-6: a source default is an annotation and inserts nothing.
    if ('default' in top) {
      const r = zod.safeParse(undefined);
      const carried = typeof zod.meta === 'function' && 'default' in (zod.meta() ?? {});
      facts.defaults.push({
        op: opId,
        slot,
        default: top.default,
        required,
        acceptsAbsent: r.success,
        inserted: r.success ? r.data : undefined,
        inserts: r.success && r.data !== undefined,
        carriedInMetadata: carried,
      });
    }
    // Annotations at the slot's top level, read back from the loaded Zod schema.
    const meta = typeof zod.meta === 'function' ? (zod.meta() ?? {}) : {};
    for (const [key, metaKey] of [
      ['description', 'description'],
      ['example', 'examples'],
      ['title', 'title'],
    ]) {
      if (key in top) {
        facts.annotations[key][1] += 1;
        const carried =
          key === 'example'
            ? isDeepStrictEqual(meta.examples, [top.example])
            : meta[metaKey] === top[key];
        if (carried) facts.annotations[key][0] += 1;
      }
    }
  }
}

const rows = [...tally.entries()]
  .sort(([a], [b]) => a.localeCompare(b))
  .map(([keyword, t]) => ({ keyword, ...t }));
const boundaryRows = new Map();
for (const b of boundary) {
  const key = b.what
    .replace(/ for (parameter|response|request).*$/, ' (per slot)')
    .replace(/response \d+ headers/, 'response headers');
  const r = boundaryRows.get(key) ?? { what: key, ok: 0, notOk: 0, examples: [] };
  if (b.ok) r.ok += 1;
  else {
    r.notOk += 1;
    if (r.examples.length < 2) r.examples.push({ op: b.op, detail: b.detail });
  }
  boundaryRows.set(key, r);
}
const result = { label, facts, constraints: rows, boundary: [...boundaryRows.values()] };
writeFileSync(path.join(outDir, `result-${label}.json`), JSON.stringify(result, null, 1));
console.log(
  `${label}: ops ${facts.ops}, generated ${facts.generated}, rejected ${facts.rejected.length}, slots ${facts.slotsScored}/${facts.slots}, objects closed by profile ${facts.closedByProfile}`,
);
for (const r of rows)
  console.log(
    `  ${r.keyword.padEnd(50)} samples ${String(r.samples).padStart(5)}  agree ${String(r.agree).padStart(5)}  disagree ${String(r.disagree).padStart(4)}  (ref accepts ${r.refAccepts}, rejects ${r.refRejects})`,
  );
for (const b of result.boundary)
  console.log(`  [boundary] ${b.what.padEnd(40)} ok ${b.ok} not ${b.notOk}`);
console.log(
  '  base invalid:',
  facts.baseInvalid.length,
  '| produced checked',
  facts.produced.checked,
  'changed',
  facts.produced.changed.length,
  '| defaults',
  facts.defaults.length,
  'inserting',
  facts.defaults.filter((d) => d.inserts).length,
  'carried in metadata',
  facts.defaults.filter((d) => d.carriedInMetadata).length,
  '| annotations',
  JSON.stringify(facts.annotations),
);
```
